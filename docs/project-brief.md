# BookCycle Project Brief

## Purpose

BookCycle is a learning web project created to develop and apply practical knowledge in Web Operations, website management, and core web technologies in an environment that reflects real project work.

## Current Phase

The project is currently in the initial setup phase. The existing infrastructure has been reviewed, and development will begin incrementally through defined tickets.

## Core Concept

BookCycle is a platform where users can sell, exchange, or give away second-hand physical books. The platform will connect people who have books they no longer need with people looking for them, while the actual transaction between users takes place outside the platform.

## Initial Scope

- Book catalog
- Individual book listings
- Sale, exchange, and giveaway listing types
- Basic search and filtering
- Responsive and accessible interface

## Out of Scope for Initial Phase

- Payment processing
- User accounts and profiles
- Direct communication between users
- User-generated book uploads
- Advanced search and filtering

## Planned Environments

- Local development — used for development and initial testing.
- Staging — used for QA and validation before production releases.
- Production — the live public environment used by real users.

## Key Operational Principles

- Use staging before production changes.
- Do not store secrets or credentials in the repository.
- Do not make direct production changes without review.
- Create backups before destructive changes.
- Document infrastructure changes.
- Keep staging and production environments separated.
