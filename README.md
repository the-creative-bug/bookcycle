# BookCycle

BookCycle is a learning web project for a platform where users can list physical second-hand books for sale, exchange, or giveaway.

## Current status

Project setup and discovery phase.

## Planned initial stack

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Environments

- Local development
- Staging planned
- Production later
